# Lumio

An AI-free, offline-first learning app in a single file (`lumio.html`) with an optional tiny leaderboard server (`server.js`).
Everything is stored in your browser (localStorage). There are no accounts, no paid services and no API keys.

## Files
- `lumio.html`: the whole app (HTML, CSS, JavaScript, embedded owl and logo images).
- `server.js`: optional leaderboard server, Node.js only, no dependencies. Creates `leaderboard.json` next to it.
- `README.md`: this file.

## Run
1. Simplest: double-click `lumio.html` (Chrome, Edge, Firefox or Safari).
2. With the leaderboard: install Node.js 18 or newer, run `node server.js`, open http://localhost:3000, then press **Sync & refresh** on the Leaderboard page. Set `PORT=4000` to change the port.

## External dependencies (all optional)
- Python lab: downloads Pyodide v0.26.4 from cdn.jsdelivr.net the first time you run Python (about 10 MB, needs internet).
- Heading font: Plus Jakarta Sans from Google Fonts (falls back to a system font offline).
- Leaderboard: your own `server.js`. Nothing is sent unless you press Sync.

## Replacing assets
The owl and logo images are embedded as base64 WebP inside `lumio.html` (search for `data:image/webp`). To replace them with the original full-resolution files, convert your PNGs to WebP or PNG and swap the `data:` strings, or change the `src` values to files in an `assets/` folder next to `lumio.html`.

## What is implemented
- Onboarding for School Student, Dropper and Above Class 12; board and class choice (Nursery to Class 12); name, goals, exam date and weak areas; learner-appropriate subject lists (school catalogue, four exam subjects for droppers, 24 topic areas plus a custom goal for above-12 learners).
- Time-based themes (morning 06:00-16:59, evening 17:00-18:59, night 19:00-05:59) with manual override.
- Scheduler with session slots, lessons locked until the start time, session limits and rescheduling; Sunday and study-time settings.
- Chapter flow: notes, key points, flashcards, checklist, quiz with explanations, mastery tracking (scales with chapter length), two revision sessions, mock tests with review of missed questions, complementary 15-minute session unlocked by a completed chapter.
- XP (awarded once per activity), streaks with best streak, achievements including 3, 7, 14, 30, 60 and 100-day streak milestones, progress dashboard that separates completion from mastery.
- Games and labs by age band: Number Hop, Match the Pictures, Spell the Word (Nursery to Class 5); Pendulum Lab (Classes 6-8); Projectile Lab, Chemistry, Genetics, Modelling, Budget, History and Geography games; Spaceship builder with saved designs; Coding Lab (JavaScript and Python, tests, hints, three debugging exercises); AI Lab and AI Fairness Lab (made-up data); Web Workspace.
- Printable worksheet with answer key, local note uploads (.txt and .md), study reminder (browser notification while the tab is open), guardian summary (consent, this device only, printable weekly report), leaderboard with display name and opt-out.

## Content status (important)
- Chapter, question and game content is **Lumio sample material**. It is not official curriculum, not a textbook, and contains no previous-year questions.
- Class 11 Physics has a 14-chapter title outline (from education sites, not the official PDF) and three Lumio-written chapters (Units and measurements, Motion in a straight line, Gravitation), plus one Python chapter.
- Official board links in the app: CBSE Academic, CISCE publications, UPMSP, NIOS. Lumio does not copy their syllabus content.
- ICSE schools below Class 9 and UP Board learners see a note explaining that official chapters are not included; ICSE Class 8 syllabuses vary by school.

Spaceship game: a brute-force search found that the original "Low Earth orbit from the ground" mission had no winning design. Engine count (1 to 6) was added and the one-stage target set to 9.0 km/s (stated in the game as simplified). A winning design now exists (for example 2 Hydro-X engines, 220 t fuel, 2 t hull, 1 t payload) and a high-Δv, low-thrust design correctly fails on thrust-to-weight. Chemistry (all four equations, smallest-whole-number rule) and Genetics (all nine crosses) were also verified for correctness.

Checklist E (social features), built on the optional server and tested with three separate browsers against a real `server.js`: friend codes with requests, accept, decline and remove; friends list with streak, weekly XP and a shared friend streak (days when both learned, from self-reported dates); cooperative weekly friend quests (team XP 300 and both learning on 4 days); activity feed of streak milestones and new achievements for you and your friends; a real weekly league (up to 10 learners from the same class group, ranked by XP earned this week, nobody invented); and focus rooms with a shared server-timed countdown and presence (polls every 3 seconds, not true push). Works only when Lumio is opened from the server (http://localhost:3000) and the learner has a display name and has not opted out of leaderboards.

Checklist F (accounts and online infrastructure), built into `server.js` and the Account screen, tested with an API test (46 checks) and a four-device browser test: learner and parent accounts (username and password hashed with scrypt, 30-day session tokens stored hashed, lockout after 5 wrong attempts); recovery codes (8 one-time codes, shown once) and phone-OTP recovery; phone number verification and phone-code sign-in (6-digit codes, 10-minute expiry, 5 tries, resend limits, no account enumeration); cross-device sync of progress with a merge (best quiz scores, larger XP, union of learning days, flashcards, mocks, papers; schedule and settings come from the device you sync from; uploaded notes stay on the device); parent link by learner-created invite code (single use, 24 hours), a parent summary shown only while the learner's consent is on, and in-app parent and learner messages with an unread count; profile nickname and visibility (private by default); and an account leaderboard that counts at most 800 XP gain per day per account (flags larger jumps). Honest limits: OTP codes are only SMS-delivered if the server is started with SMS_WEBHOOK_URL pointing at your SMS provider's endpoint (it receives {to,text}); otherwise the server runs in dev mode and prints the code to its console. Real SMS delivery was NOT tested. The "cloud database" is a JSON file (`accounts.json`) written atomically; move to a managed database and put the server behind HTTPS before real use. XP is capped and flagged but still reported by the browser, so the leaderboard is "server-limited", not verified. Lockouts and OTP counters live in memory and in the file respectively; there is no CAPTCHA, no email, and no admin recovery if both password and recovery codes are lost. Parent notifications are in-app messages only.

## Known limitations and security notes
- localStorage is not encrypted and is per browser; clearing site data deletes progress. Reset in Settings clears it too.
- JavaScript exercises run in a Web Worker with a 2-second limit. A Worker has no page access, but it is not a network sandbox, so only run code you trust. Python runs in Pyodide (WebAssembly) inside a Worker.
- The leaderboard server has no accounts or rate limiting, stores display names and XP in plain JSON, and trusts the XP your browser reports. Do not expose it to the public internet as is.
- The guardian view is a screen on the same device. No messages or notifications are sent, and no identity or consent is verified beyond a checkbox.
- Bottom navigation labels are 10.5 px so seven items fit on a phone.

### New server settings (all optional)
| Variable | Default | Meaning |
|---|---|---|
| `RATE_PER_MIN` | 120 | API requests per client per minute |
| `REGISTER_PER_HOUR` | 10 | New accounts per client per hour |
| `TRUST_PROXY` | off | Set to `1` behind a hosting proxy so the real visitor address is used and HSTS is sent for HTTPS visits |
| `BACKUP_DIR` | `./backups` | Where backups are written (private folder) |
| `BACKUP_KEEP` | 14 | How many backups to keep |
| `BACKUP_EVERY_MS` | 21600000 | Backup interval (6 hours) |
Backups are on the same disk. Copy them off the machine yourself for real protection.
